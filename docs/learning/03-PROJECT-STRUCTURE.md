# 03 - Project Structure

## 🎯 What You'll Learn

- Where everything lives in the project
- What each folder does
- How files connect to each other
- Where to find things when you need them

## 📁 The Big Picture

```
retitle-extension/
├── src/              ← Your code lives here
├── dist/             ← Built files (what Chrome uses)
├── public/           ← Static files (icons, manifest)
├── tests/            ← Test files
├── docs/             ← Documentation (you are here!)
└── node_modules/     ← Dependencies (don't touch)
```

## 📂 Source Code (`src/`)

This is where all your code lives. Think of it as your workshop.

### `src/background/`
**What:** The "brain" of the extension
**Contains:**
- `service-worker.ts` - Main background script
- `storage-manager.ts` - Handles saving/loading data

**When you'd edit:** When you need to change how data is saved or how the extension responds to events

### `src/content/`
**What:** Code that runs on web pages
**Contains:**
- `title-updater.ts` - Changes page titles

**When you'd edit:** When you need to change how titles are modified on pages

### `src/popup/`
**What:** The popup window interface
**Contains:**
- `popup.html` - The HTML structure
- `popup.ts` - The JavaScript logic
- `styles/popup.css` - The styling

**When you'd edit:** When you want to change what the popup looks like or how it works

### `src/options/`
**What:** The options/settings page
**Contains:**
- `options.html` - The HTML structure
- `options.ts` - The JavaScript logic
- `styles/options.css` - The styling

**When you'd edit:** When you want to change the settings page

### `src/shared/`
**What:** Code used by multiple parts
**Contains:**
- `types.ts` - TypeScript type definitions
- `messages.ts` - Message formats for communication
- `utils.ts` - Helper functions
- `constants.ts` - Fixed values

**When you'd edit:** When you need to add new message types or shared utilities

### `src/components/`
**What:** Reusable React components (for future use)
**Contains:**
- `ui/` - shadcn/ui components

**When you'd edit:** When migrating to React or adding new UI components

### `src/lib/`
**What:** Utility libraries
**Contains:**
- `utils.ts` - Helper functions (like merging CSS classes)

**When you'd edit:** When you need new utility functions

### `src/styles/`
**What:** Global styles
**Contains:**
- `globals.css` - Global CSS with theme variables

**When you'd edit:** When you want to change colors or global styling

## 📦 Built Files (`dist/`)

**What:** Compiled, ready-to-use files
**Contains:** JavaScript, HTML, CSS that Chrome actually runs

**Important:** 
- Don't edit files here directly!
- They're generated by `npm run build`
- This is what gets loaded into Chrome

**Think of it like:** A restaurant's finished dishes (you don't cook there, you cook in the kitchen `src/`)

## 🎨 Public Files (`public/`)

**What:** Files that get copied as-is
**Contains:**
- `manifest.json` - Extension configuration
- `icons/` - Extension icons

**When you'd edit:** When you need to change extension metadata or icons

## 🧪 Tests (`tests/`)

**What:** Automated tests
**Contains:**
- `e2e/` - End-to-end tests (full user flows)
- `pages/` - Page Object Models (test helpers)
- `fixtures/` - Test setup code
- `helpers/` - Test utilities

**When you'd edit:** When adding new tests or fixing broken ones

## 📚 Documentation (`docs/`)

**What:** Learning and reference materials
**Contains:**
- `learning/` - These guides you're reading!

**When you'd edit:** When you learn something new and want to document it

## ⚙️ Configuration Files (Root)

### `package.json`
**What:** Project configuration and dependencies
**Contains:**
- List of packages the project uses
- Scripts you can run (`npm run build`, etc.)

**When you'd edit:** When adding new dependencies or scripts

### `tsconfig.json`
**What:** TypeScript configuration
**Contains:** Settings for how TypeScript compiles

**When you'd edit:** Rarely, only if you need to change TypeScript settings

### `vite.config.ts`
**What:** Build tool configuration
**Contains:** How Vite builds the project

**When you'd edit:** When you need to change how the project builds

### `tailwind.config.js`
**What:** Tailwind CSS configuration
**Contains:** Theme colors, styling settings

**When you'd edit:** When you want to change colors or add custom styles

### `playwright.config.ts`
**What:** Test configuration
**Contains:** How Playwright runs tests

**When you'd edit:** When you need to change test settings

## 🔄 How Files Connect

### Example: Saving a Title

```
User clicks "Save" in popup.html
    ↓
popup.ts sends message
    ↓
service-worker.ts receives message
    ↓
storage-manager.ts saves to Chrome storage
    ↓
service-worker.ts sends message to content script
    ↓
title-updater.ts changes the page title
```

### File Dependencies

```
popup.ts
  → imports from shared/messages.ts
  → imports from shared/utils.ts
  → imports from shared/types.ts

service-worker.ts
  → imports from shared/messages.ts
  → imports from storage-manager.ts
  → imports from shared/utils.ts
```

## 🎯 Where to Find Things

**"I want to change how titles are saved"**
→ `src/background/storage-manager.ts`

**"I want to change the popup appearance"**
→ `src/popup/popup.html` and `src/popup/styles/popup.css`

**"I want to add a new feature"**
→ Usually starts in `src/popup/` or `src/background/`

**"I want to change extension settings"**
→ `public/manifest.json`

**"I want to add a test"**
→ `tests/e2e/`

**"I want to understand how messages work"**
→ `src/shared/messages.ts`

## 📝 Naming Conventions

- **Files:** `kebab-case.ts` (like `popup-page.ts`)
- **Folders:** `kebab-case` (like `content-scripts`)
- **Components:** `PascalCase` (like `PopupPage`)
- **Functions:** `camelCase` (like `saveTitle`)
- **Constants:** `UPPER_SNAKE_CASE` (like `MAX_STORAGE_SIZE`)
