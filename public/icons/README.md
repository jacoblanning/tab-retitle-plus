# Generated extension icons

These PNGs are generated from the canonical SVGs in
`design/icons/retitle-plus/`.

- Run `npm run assets` after changing SVG geometry.
- Run `npm run assets:check` to verify committed PNGs are current.
- Chrome toolbar sizes (16 and Retina 32) use the filled optical-size source.
- Larger sizes (48 and 128) use the outlined master.

Do not edit the PNGs directly.
